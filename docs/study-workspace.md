# 视听标注工作区

适用于本仓库的 Rust GUI。打开视频或 `.shotlab` 项目，进入 **分析 → 视听标注**。工作区有 8 个页签：「时间层 · 场景」「动画曝光表」「对白 · 音画核对」「镜头关系」「证据与裁决」「声音链接」「色彩 / 构图」「跨集 · 查询」。所有记录以源视频显示帧为坐标，区间写作 `[start, end)`，终点不包含；标注从 0 起计，不随镜头拆并被截断。

## 观察范围与回看

`观察范围` 独立于统计页的镜头筛选。可选择当前镜头、全片、把当前播放帧设为起点或终点，也可以直接用帧号输入。点击时间条、标注条目、曝光段、关系证据帧、声画切点或查询命中镜头可回看；支持逐帧与「循环观察范围」。音频循环、波形、频谱和导出使用同一组源时间戳，可变帧率素材按帧索引中的实际 PTS 换算。

预览会根据页签叠加不同参考元素：曝光页显示 ROI 与洋葱皮，关系页画仍有效的镜头关系连线，色彩页画三分线、中心线、安全区、人工主体框和排除掩码。这些叠加层只是阅读辅助，不修改源视频，也不自动写成结论。

## 时间层与场景

1. 展开「标注层与词表」，添加场景、角色、对白、音乐、运镜和动作模板；重复添加不会产生重复层。
2. 新建自定义层可填写逗号分隔的词表。词表非空时，标注内容受词表约束；空词表允许自由文字。
3. 选定观察范围，用「用观察范围新建标注」填写内容、角色/说话人、备注、出处、作者和核对状态。
4. 在列表中点击条目可修改，保存后原始自动来源与人工修订状态分别保留。只有空层可以直接删除。

同一场景、对白或动作允许跨多个镜头；各层也允许重叠。对白/音乐覆盖率按对应层的区间并集计算，描述的是「已标注时间占比」，不是自动测得的真实对白或音乐占比。

## 动画曝光表、阶段模板与连续帧

1. 在预览上拖拽框选角色或局部区域；「重置为全画面」恢复完整画面。可开启前后各两帧洋葱皮。
2. 生成曝光表（单次最多 5,000 帧，可取消）。自动边界与人工修订边界分别保存，可逐帧回看、拆分、合并、确认核对或恢复估计。
3. 选择 `classic` / `impact` / `minimal` 动作阶段模板；模板写入当前曝光表的阶段说明，不覆盖人工拆分边界。
4. 「导出差图 / 连续帧…」输出编号 `000001.png` 起的选区连续帧、相邻帧平均绝对差图和清单 JSON。清单含源文件信息、相对源时间、修订边界、阶段、ROI、作者和核对状态。差图只表示成片中可见变化，不能据此推定制作原画张数。

曝光估计容易受摄影平移、特效、嘴形、压缩噪声和多个动画层影响。30/60 fps 素材应先检查帧序；只有确认 telecine 下拉时才考虑 IVTC。重复导出到同一路径会被拒绝，任务取消会清理本次写出的部分文件。

## 对白、频谱与声画核对

- 「载入 SRT」后可把字幕导入对白层；导入初始为待核对，重复导入不会覆盖人工修订。编辑后的对白可同步到播放字幕。
- 「载入波形与声画候选」生成 PCM 峰值波形、对数频谱列和粗分声音片段。三者与画面共用源时间轴；点击波形或频谱可定位。频谱由本地 11 kHz 单声道 PCM 的 NumPy FFT 生成，粗分标签只是听辨线索，不是 ASR 或音乐分轨。
- 切点列表同时显示自动声学候选和人工核对选项：确认 J-cut、L-cut、同步、非声音桥或待核对。切点或相邻镜头范围变化后，旧判断自动失效。
- 「声音链接」页可把观察范围与说话人、角色、画内/画外/待核对位置及出处关联。报告列出镜头和场景的未标注对白时长；只有已核对的对白区间覆盖整个范围，才显示该范围「已核对」。**未标注对白不等于没有对白**。
- 可选 ASR 适配器只接受用户自备的识别片段；载入时必须填写模型、模型版本、来源和作者。程序不调用模型、不下载权重、不把外部结果覆盖到人工对白/说话人判断；适配器未安装或没有结果时给出状态。设计依据见 [开源复用核查](open-source-reuse.md)。

## 镜头关系、证据与裁决

「镜头关系」页按镜头 ID 记录正打/反打、视线匹配、动作接戏、图形匹配、平行剪辑、母题和转场等类型化断言，并附证据帧、转场类型、解释、作者和核对状态。关系报告中会区分当前边界仍有效的关系与因镜头编辑而失效的旧关系；失效关系不会自动套用到新切点。

「证据与裁决」页把**记录 / 出处**和**判断 / 解释**放进不同字段，可写参考文献、标注人、复核人并保存当前帧的截帧附件路径（附件不会复制进项目）。同一证据帧出现不同判断时，分歧报告列出双方意见；裁决写入单独记录并保留原始卡片。证据卡同时保存软件、源文件、模型和提示词版本，可导出到研究包。

## 色彩与构图

「色彩 / 构图」页用归一化 `[x, y, 宽, 高]` 的 ROI、多块排除掩码和人工主体框采样单帧。可把黑边、字幕带或台标排除后计算保留像素的 sRGB 均值、感知亮度和饱和度；辅助线包括三分线、中心线和 10% 安全区，主体位置按归一化中心归到九宫格区域。

采样的自动数值作为 `observation` 保存，文字解释作为人工 `judgment` 单独保存。区域色值是观察证据，不代表自动主体检测、色彩叙事结论或跨镜头风格分类。

## 组合查询、版本对齐与跨集比较

「跨集 · 查询」页可按文字、标签、景别、运镜、时长、静止率、作品信息和时间层类型建立并保存查询；运行后列出命中镜头与排除数量。运动静止率来自当前会话的运动分析；已保存项目文件不含运动结果，因此跨片比较不会把缺少的静止率条件误判为命中。

在 **分析 → 研究 → 重复镜头 · 多片比较** 中选择多个 `.shotlab`，可指定 `shot / scene / film / episode` 推断单位、当前项目中保存的组合查询和人工版本锚点。先排除区段，再对查询命中的镜头汇总。场景单位用每个已标注场景的平均镜头时长；每侧少于两个样本时只显示描述统计，因此按影片或集逐对比较时不计算显著性。结果列出逐片命中数、分层汇总和每片等权均值。

人工锚点每行写作 `第一版镜头, 第二版镜头, composition_similarity|material_reuse, 备注`，可保存到当前项目；比较时未另填锚点会读取当前项目首条保存记录。共享哈希独立于查询范围，只提示可能的素材复用。

## 保存、撤销与交换

所有新集合（关系、证据、裁决、声音链接、色彩观察、版本对齐、保存查询）随 `.shotlab` 项目保存并进入同一条撤销/重做链。旧项目按 schema v2 默认值打开；导入与导出都记录软件版本、研究 schema 版本、源文件版本和 provenance。

顶部「导出 JSON / EAF / CSV 包…」一次生成 6 个同名前缀文件：

- `.json`：完整、版本化的研究数据；EAF 不能表达的复杂字段以此文件为准。
- `.eaf`：依据公开的 EAF 3.0 规范生成的受限投影，含毫秒 `TIME_SLOT`、`TIER / ANNOTATION / ALIGNABLE_ANNOTATION / ANNOTATION_VALUE`、受控词表、类型化 `CROSS_REF_LINK` 和 JSON 投影。
- `.events.csv`、`.exposures.csv`、`.relations.csv`、`.evidence.csv`：便于表格检查的长表。

「导回 JSON…」与「导回 EAF…」先检查版本、帧范围和标注引用，再按记录 ID 合并缺项。新导出的标注包带有源文件抽样指纹，旧包使用可用的源文件信息校验。重复导入不产生新记录，也不新增撤销步骤。外部修改 EAF 已有时间层标注的文本或时间后，可将修订导入新项目；当前项目若已有不同的同 ID 标注，会保留本地版本并显示冲突数。EAF 的 `LICENSE` 元素写明数据权利由用户声明、源媒体权利单独处理。导出使用新文件名前缀。

研究长表和方法说明还包含场景标签、对白/音乐覆盖率、人工音画核对、VLM 证据帧号与相对源时间、采样方法、软件与提示词版本。默认按镜头时长从 3 张基准帧逐步增加，最多 6 张。完整字段口径见 [验收口径](acceptance-criteria.md)。

## 开源复用与验证范围

添加功能前已核查 [开源项目与数据集](open-source-reuse.md)：借用了 EAF 3.0 公开格式、ClipShots MIT 的帧区间/重叠评测思想、AdA 的「记录/判断」分离、VIAN 的区域掩码概念和 Sonic Visualiser 的波形/频谱同时间轴呈现。没有把 ELAN GPL 源码、下载到本地的规范副本、CC BY-SA / NC 数据、版权影片、关键帧、模型或权重写入仓库。可选 ASR 适配器只记录用户自备结果的出处。

合成基线验证了源帧标注持久化与撤销、EAF/JSON 往返与幂等导入、毫秒到源帧映射、曝光修订与取消、差图和连续帧、波形/频谱/声音粗分、场景级无对白报告、证据分歧与裁决、ROI/构图、组合查询、逐片分层等权统计、VLM 证据帧与导出覆盖保护。真实动漫、电影、不同压缩质量与复杂声场下的人工参考集验收仍待完成；合成测试通过只证明实现与数据契约正确，不给真实素材准确率数字。
