# 新研究功能的验收口径

本文件定义功能完成后如何验证，避免把「界面能点」误当作分析有效。自动测试与人工参考集回答的是不同问题：前者保证数据、时间坐标和撤销/导出的正确性，后者衡量在真实素材上的观察质量。

## A. 合成基线（随仓库自动运行）

使用 `tests/anime_fixtures.py`、`tests/sound_fixtures.py` 和本轮新增的合成帧/音轨生成测试素材，覆盖以下固定命题：

| 能力 | 可复现基线 | 通过标准 |
| --- | --- | --- |
| 多层时间标注、EAF/JSON 交换 | 同一源视频中重叠的层、跨镜头事件、词表、作者与状态 | 源帧 `[start,end)`、毫秒时间槽、`ANNOTATION_VALUE`、受控词表和属性式层间引用往返不变；通用 EAF 毫秒可映射到源帧；导入再次执行不产生重复、不覆盖人工修订；旧项目缺字段按 schema v2 默认值打开 |
| 曝光差图、阶段模板、连续帧导出 | 已知帧序列中局部保持、全画面变化与混合变化；人工拆分/合并后的曝光表 | 差图只反映选区；阶段模板不会覆盖人工修订；导出编号从 `000001` 连续、清单含源帧/相对秒/ROI/修订状态；目录已存在或文件已存在时拒绝写入 |
| 声音分层与无对白报告 | 带已知静音、频带变化、字幕/对白层和 scene 层事件的音轨 | 频谱与 PCM 波形共享时间零点；说话人—画面角色—画外音链接可由人工确认；镜头与场景的无对白时长由区间并集计算，未标注明确显示「未核对」；可选 ASR 缺失时不影响内置分析，用户提供片段时必须带模型/版本/来源/作者 |
| 镜头关系 | 已知相邻与非相邻镜头、转场区间、作者与理由 | 关系类型受控、端点使用镜头 ID；连接线在时间轴上可定位；删除/改动镜头后旧关系被标为失效而非悄悄套用 |
| 色彩/构图 | 指定色块、黑边、字幕带和主体方框 | 归一化 ROI 与排除掩码按并集生效；区域均值/亮度/饱和度只统计保留像素；三分线/中心线/安全区与主体位置使用同一归一化坐标；观察与判断字段分开 |
| 证据与裁决 | 同一帧的两位标注人给出不同判断，附不同出处 | 「记录/出处」与「判断/解释」分别保存；分歧视图列出双方及状态；裁决写入单独记录并保留原意见；导出含软件、源文件、模型/提示词、素材版本与标注人信息 |
| 跨集查询与比较 | 两至三个含不同集数、标签、时长、镜头、保存查询和版本差异的项目 | 组合查询逐片逐镜头应用同一条件，输出逐片命中数；人工锚点允许插删镜头并标出版本差异；构图相似与素材复用分开统计；每片等权重、`series/episode/film/scene/shot` 明确分层与推断单位都写入结果，不把镜头当作独立影片样本；共享哈希只标可能素材复用 |
| VLM 证据帧与自适应采样 | 长短不同的镜头和 `unknown` 枚举 | 长镜头取更多有界关键帧；证据帧编号/源时间随标签保存；`unknown` 映射为 `None`；方法说明记录模型、提示词版本、采样数与帧号 |

## B. 人工参考集（研究者按素材情况执行，不随仓库分发）

推荐用 Blender 开放电影的两段短片做手工标注：

- **Big Buck Bunny**，CC BY 3.0，按 [官方署名要求](https://peach.blender.org/about/) 标注 `© copyright 2008, Blender Foundation / www.bigbuckbunny.org`；
- **Sintel**，CC BY 3.0，按 [官方署名要求](https://durian.blender.org/sharing/) 标注 `© copyright Blender Foundation | durian.blender.org`，播放整片保留片尾字幕。

影片由研究者自行下载，仓库不附带影片或截帧。每段选取 3–5 分钟，至少两位标注人独立记录：硬切/渐变区间、镜头关系、对白与画外音、主体区域与构图、阶段/色彩观察，以及每条结论的证据帧和出处。记录源文件大小、修改时间、时长、帧率、版本/来源、标注人和裁决人。争议由第三人裁决，保留原始意见。

电影分析可另用 [AdA 人工标注](https://projectada.github.io/annotations/)（CC BY-SA 3.0）作为术语/时间码对照，但它只覆盖其自带影片，且影片本身不包含在标注数据中；不能把该语料当作动画准确率基准。

## C. 报告指标与限制

- 镜头边界按半开区间重叠做一对一匹配，分别报告硬切与渐变的 precision / recall / F1。零容差下仅相邻的区间不算命中；只有预测的影片也计入误检。
- 自动曝光、声学候选、颜色聚类、VLM 标签分别与人工参考比较；分别报告可核对镜头数、人工修订数、`unknown` 数、失败数。自动结果不得覆盖人工结论。
- 跨片统计报告样本是镜头、场景、影片还是集；镜头数不等的影片用每片等权重汇总，分层结构须说明推断单位。共享哈希只能提示可能的素材复用，构图相似必须单独命名。
- 人工参考集尚未完成时，文档和界面只能写「尚未在真实素材上验证」，不能给准确率数字。合成基线通过只证明实现与数据契约正确。

## D. 操作验收

运行 `$env:PYTHONUTF8='1'; & E:\CadensView\.venv\Scripts\python.exe -m unittest discover -s tests`、在 `E:\CadensView\gui` 运行 `cargo test` 与 `cargo build --release` 均通过。再打开 GUI 检查：8 个页签可见、选择范围/运行任务/编辑/撤销/保存/导出不互相覆盖、JSON 与 EAF 可导回、证据附件只写路径、后台任务可取消、切换项目后不采用旧任务结果。真实素材人工验收按 B 节另行执行，仓库目前不附带其影片、截帧或参考标注。
